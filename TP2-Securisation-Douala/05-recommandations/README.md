# Recommandations — Une page à rédiger par les étudiants

Développer brièvement les points suivants en fonction du laboratoire :

1. Ordre de déploiement dans les autres agences et justification.
2. Risques de coupure identifiés et retour arrière prévu.
3. Matériel nécessaire, compatibilités et coûts à confirmer.
4. Vérifications à réaliser avant généralisation, notamment les fonctions non validées à Douala.

Distinguer les mesures effectivement testées des recommandations.
